## 📜 Кодекс поведения
- Будьте уважительны к другим участникам
- Конструктивно принимайте критику
- Фокусируйтесь на том, что лучше для сообщества
- Проявляйте эмпатию к другим участникам

## 🚀 С чего начать
1. **Форкните репозиторий**
2. **Клонируйте свой форк:**
```bash
git clone https://github.com/YOUR-USERNAME/fastapi-blog
cd fastapi-blog
```

3**Следуйте инструкциям в [README.md](README.md) для настройки окружения и запуска проекта.**
4**Установите pre-commit хуки:**
```bash
pre-commit install
```

   
## 💻 Процесс разработки

1. **Создайте новую ветку для вашей задачи:**
```bash
git checkout -b my-feature-branch
```

2. **Внесите изменения и следуйте правилам коммитов:**

Формат коммита:
```
<тип>(<область>): <описание>
feature(api): добавлен новый эндпоинт
fix(ui): исправлена ошибка в компоненте
docs(readme): обновлено описание проекта
```

3. **Запустите тесты:**
```bash
pytest
```

## 🎨 Стиль кода
- Используйте ruff для форматирования кода
- Следуйте PEP 8 для Python
- Используйте аннотации типов
- Пишите тесты для нового функционала
- Используйте docstrings для функций и классов
- Следуйте принципам SOLID и DRY


## 🛠️ Создание пул-реквеста
1. **Убедитесь, что ваш код работает и все тесты проходят.**
2. **Закоммитьте ваши изменения:**
```bash
git add .
git commit -m "feat(<область>): <описание>"
```
3. **Запушьте вашу ветку:**
```bash
git push origin my-feature-branch
```

4. **Создайте пул-реквест:**
   - Перейдите на страницу вашего форка
   - Нажмите на кнопку "Compare & pull request"
   - Заполните описание и нажмите "Create pull request"
   - Убедитесь, что ваш пул-реквест соответствует правилам проекта и не нарушает кодекс поведения
   - Ожидайте отзывов от других участников проекта
   - Внесите изменения, если это необходимо
   - После одобрения пул-реквеста, дождитесь его слияния с основной веткой
   - Удалите вашу ветку после слияния, если это необходимо
   - Поблагодарите всех участников за их вклад и поддержку
   - Обновите ваш форк, чтобы он оставался актуальным с основной веткой
   - Следите за обсуждениями и отзывами по вашему пул-реквесту
   - Если у вас есть идеи для улучшения проекта, не стесняйтесь делиться ими в обсуждениях или создавать новые задачи
   - Участвуйте в жизни сообщества, помогайте другим участникам и делитесь своим опытом
   - Следите за обновлениями проекта и новыми релизами
   - Если у вас есть вопросы или предложения, не стесняйтесь обращаться к другим участникам или администраторам проекта
   - Помните, что участие в проекте - это не только код, но и общение, обмен опытом и знаниями
